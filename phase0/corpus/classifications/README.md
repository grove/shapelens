# Classification records

Create these records only after the corpus passes `freeze-check` and the frozen inputs have been committed. Copy [`../../templates/classification.json`](../../templates/classification.json) once per frozen question.

Reason codes use lower-case snake case and should name the precise missing operator, selector, lens use, identity rule, shape problem, semantic declaration, or ordinary-code advantage. New observed blockers are allowed; do not force them into a predetermined feature list.
